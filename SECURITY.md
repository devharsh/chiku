# Security Policy

## Supported Versions

We officially support the following versions of Chiku with security patches. We recommend all users stay on the latest version.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take Chiku's security seriously. If you believe you have found a security vulnerability, please follow these steps:

1.  **Do not open a public issue.** This helps prevent the vulnerability from being exploited before a fix is ready.
2.  **Private Reporting:** Please use the [GitHub Security Advisory](https://github.com/devharsh/chiku/security/advisories/new) feature to report the vulnerability privately.
3.  **Alternative:** Alternatively, you can email the maintainer at `devharsh at live dot in`.

### What to expect
* **Acknowledgment:** You will receive an initial response within 48-72 hours if you don't mind.
* **Updates:** We will provide status updates at least once a week while a fix is being developed.
* **Disclosure:** Once a fix is released, we will coordinate a public disclosure and give you proper credit for the discovery.
